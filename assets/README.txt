========================================================================
FOLDER ASSETS PORTOFOLIO - HUMAM ASATHIN HAQQANI
========================================================================

Folder ini disiapkan untuk menampung seluruh aset foto dan dokumen Anda:

1. FOTO PROFIL:
   - Berkas: assets/profile.jpg
   - Cukup masukkan foto profil Anda ke folder ini dengan nama "profile.jpg" (format JPG/PNG/WEBP).
   - Website sudah disetel untuk memuat "assets/profile.jpg".
   - Jika berkas belum ada, website otomatis menampilkan placeholder siluet (profile-placeholder.svg) secara elegan.

2. BERKAS CV:
   - Berkas: assets/cv-humam.pdf
   - Masukkan resume/CV Anda ke folder ini dengan nama "cv-humam.pdf".
   - Tombol "Unduh CV" di bilah navigasi atas (header) dan menu mobile sudah langsung terhubung ke berkas ini.

3. TANGKAPAN LAYAR / DOKUMEN PROYEK:
   - Anda juga dapat menaruh gambar tangkapan layar (screenshot) aplikasi Anda di sini untuk dipakai pada kartu proyek.
